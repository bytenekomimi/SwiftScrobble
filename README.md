# SwiftScrobble
The free app for all your Apple Music scrobbling needs on arm macOS! <br>
This project was made as an alternative to the official macOS last.fm scrobbling app, since that app is *still* x86 and not arm, meaning on macOS 28 it will no longer launch. <br>

Over time I'll be rewriting a lot of things once I understand and learn more and more. <br>
